# TemplaGem Landing Page

Interactive landing page for **[TemplaGem](https://github.com/TemplaGem/TemplaGem)** — a browser extension for Google Gemini prompt templates.

## Features
- **Live Gemini Sandbox**: interactive simulator of the Gemini input overlay and extension popup.
- **Variable Pill Highlighting**: interactive `{{variables}}` with `Tab` navigation and bracket stripping on send.
- **Dual Themes**: dark and light themes matching the Gemini workspace palette.
- **Bilingual**: Ukrainian (UA) and English (EN) toggle with mobile-optimized layout.

## Local Development
Open `index.html` directly in your browser, or run a local server:

```bash
npx serve -l 4173
```
